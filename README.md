# QA Automation Practice 

Collection of my automation scripts and learning projects in Quality Assurance.

# Repository Structure

- **`api_tests/`** — Automated tests for REST API (Python + Pytest + Requests).
- **`ui_tests/`** — UI automation tests using Selenium / Playwright.
- **`utils/`** — Helper functions and configuration files.

# Tech Stack

- **Language:** Python 3.10+
- **UI Automation:** Playwright / Selenium
- **API Testing:** Requests, Pytest
- **Test Runner:** Pytest
- **Reporting:** Allure Report
- **Version Control:** Git, GitHub

# How to Run

1. Clone this repository: git clone https://github.com/psergik2-boop/qa-automation-practice.git
2. 2. Install dependencies: pip install -r requirements.txt
3. 3. Run the tests: pytest
