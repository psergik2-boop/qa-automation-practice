# QA Automation Practice

Collection of my automation scripts and learning projects in Quality Assurance.

## Repository Structure

- **`api_tests/`** — Automated tests for REST API (Python + Pytest + Requests).
- **`ui_tests/`** — UI automation tests using Selenium / Playwright.

## Tech Stack

- **Language:** Python 3.10+
- **UI Automation:** Playwright / Selenium
- **API Testing:** Requests, Pytest
- **Test Runner:** Pytest
- **Reporting:** Allure Report
- **Version Control:** Git, GitHub

## How to Run

Clone this repository:

```bash
git clone https://github.com/psergik2-boop/qa-automation-practice.git
cd qa-automation-practice
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run all tests:

```bash
pytest
```

Run only API tests:

```bash
pytest api_tests/
```

Run only UI tests:

```bash
pytest ui_tests/
```

## Goals

- Practice writing clean and maintainable test code.
- Learn modern QA automation tools and frameworks.
- Build a portfolio of real-world testing examples.
